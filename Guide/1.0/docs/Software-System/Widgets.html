小工具

1、呼出小工具栏


小工具统一放置在系统的侧边栏中，点击界面两侧的“”或“”按钮，可调出侧边栏，并显示常用小工具


白板、批注、裁切、屏幕冻结，以及更多小工具入口“”，点击可查看更多小工具



2、批注工具

点击侧边栏中的“”弹出如图所示批注工具，该工具包括批注、手势擦除、文件浏览、屏幕截图、退出等功能。
使用快捷白板时，此功能按钮不可用



3、裁切工具

点击侧边栏中的“”弹出如图所示裁切工具，该工具包括裁切、手势擦除、文件浏览、屏幕截图、退出等功能。
使用快捷白板时，此功能按钮不可用



4、屏幕冻结工具

点击“”按钮弹出屏幕冻结工具，冻结屏幕画面，同时可对当前屏幕画面进行缩放



5、更多小工具

点击“”按钮弹出更多工具选择框，包含翻译、聚光灯、板中板、倒计时、秒表和倒计日等
