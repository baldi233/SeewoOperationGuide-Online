快捷白板

1、快捷白板页面介绍

点击“”启动白板



2、菜单栏

点击“”弹出菜单栏如图所示，用户可对当前文件内容及格式进行处理。例如：新建、打开、保存、导出；
同时可调整画板背景及屏幕亮度



3、操作栏

3.1、画笔工具，点击“”画笔按钮，可设置画笔颜色，笔触类型及画笔颜色



3.2、橡皮工具，点击“”橡皮按钮，可圈选删除对象



3.3、形状工具，点击“”形状按钮，可选择图形和图形颜色进行图形绘制



4、手势操作

4.1、手势擦除，手掌或手背置于屏幕，可对白板内容进行手势擦除



4.2、漫游，两个或两个以上手指按住页面，拖动手指移动当前页面



4.3、全局缩放，通过“缩放手势”均可对当前页面全局缩放
